# Customer Complaint Analysis and Resolution Performance Dashboard

## Project Overview

This project analyzes customer complaints to understand complaint categories, priorities, communication channels, assigned teams, response times, resolution times, complaint status, and customer satisfaction.

The project uses Python, Pandas, SQL, SQLite, and Power BI to clean, analyze, and visualize customer complaint data.

## Objectives

- Analyze customer complaint patterns
- Identify common complaint categories
- Compare resolved and pending complaints
- Analyze complaint priorities
- Measure response and resolution times
- Compare support team performance
- Understand customer satisfaction ratings
- Build an interactive Power BI dashboard

## Project Workflow

1. Created the customer complaints dataset
2. Loaded the dataset using Pandas
3. Cleaned and prepared the data
4. Performed exploratory data analysis
5. Created charts using Matplotlib
6. Stored the data in SQLite
7. Executed SQL queries for analysis
8. Created an interactive Power BI dashboard
9. Added charts, KPI cards, and slicers
10. Documented project insights

## Dashboard Features

- Total complaints
- Resolved complaints
- Pending complaints
- Average response time
- Average resolution time
- Average customer rating
- Complaints by category
- Complaints by status
- Complaints by priority
- Complaints by channel
- Complaints by assigned team
- Monthly complaint trend
- Category and channel filters

## Key Insights

The dashboard helps identify the most common complaint categories, pending complaints, high-priority issues, team workload, response performance, resolution performance, and customer satisfaction.
